# Code & File Naming Rules

- Never name files, directories, CMake targets, functions, classes/structs, or variables after project-management milestones, phases, epics, sprints, tasks, or deliverables (for example: `milestone_a_stubs.cpp`, `phase1_api`, `task2_helper`).
- Always use descriptive architectural, domain, subsystem, or feature names (for example: `dxcore.cpp`, `d3d12_api_test.cpp`, `compute_dispatch_test.cpp`).
